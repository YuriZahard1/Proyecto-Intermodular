# Blackjack

Blackjack clásico (sin apuestas) hecho con React 19, Vite 8, TypeScript 6 y Tailwind CSS 4.

## Cómo ejecutarlo

Requisito: Node.js 20.19+ o 22.12+ (https://nodejs.org).

```bash
npm install
npm run dev
```

Abre la URL que aparece en la terminal (normalmente http://localhost:5173).

## Otros comandos

- `npm run build`: comprueba tipos y genera la versión de producción en `dist/`
- `npm run preview`: sirve la carpeta `dist/` para probarla
- `npm run typecheck`: solo comprueba tipos
